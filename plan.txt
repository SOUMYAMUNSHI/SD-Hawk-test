Build a **production-ready, full-stack AI surveillance platform** called **SD-Hawk**.

# PROJECT OVERVIEW

SD-Hawk is an AI-powered real-time surveillance and event intelligence platform.

Unlike traditional CCTV systems that continuously record footage for humans to review later, SD-Hawk continuously watches camera feeds, understands what is happening using AI, filters out ordinary events, and creates meaningful event records. It sends notifications only when configured rules are satisfied.

The system should support homes, stores, warehouses, apartment societies, schools, offices, exam halls, parking lots, and public spaces.

Think of SD-Hawk as an intelligent security assistant that never sleeps.

The application must be designed as a scalable SaaS-ready product but should work perfectly on a local machine during development.
